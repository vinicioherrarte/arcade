## Stack and configuration

Arcade Vault is an online play platform where users compete for points. The codebase is still the create-next-app scaffold: `app/page.tsx` is template content and the metadata in `app/layout.tsx` still reads "Create Next App".

Next.js 16.4.6 with the App Router, React 19.3.0, and Tailwind CSS 4. Tailwind is wired through a Turbopack rule in `next.config.ts` (`turbopack.rules` for `*.css` using `@tailwindcss/turbopack`), not through a PostCSS config, so do not add a `postcss.config.*` file without checking whether it conflicts with that rule.

`next.config.ts` enables `cacheComponents`, `partialPrefetching`, and the experimental `agentFeedback` flag. With `cacheComponents` on, route segment configs such as `dynamic`, `revalidate`, and `fetchCache` are replaced by `"use cache"` and `cacheLife`, and uncached runtime data must sit behind `<Suspense>`. Read the matching guide in `node_modules/next/dist/docs/` before adding data fetching or caching. Middleware in Next 16 is called Proxy (`proxy.ts`).

The `@/*` path alias resolves to the project root, not to a `src/` folder, so imports look like `@/app/globals.css`.

## Styling and layout

The theme is a chain across three files. `app/layout.tsx` loads Geist and Geist Mono via `next/font/google` and exposes them as the CSS variables `--font-geist-sans` and `--font-geist-mono`. `app/globals.css` defines the color tokens `--background` and `--foreground` on `:root`, switches them under `prefers-color-scheme: dark`, and maps the font and color variables into Tailwind through `@theme inline`. Components use Tailwind utility classes such as `bg-background` and `dark:` variants, so new colors and fonts belong in `globals.css` rather than hard-coded in components.
